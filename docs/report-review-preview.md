## 검토 기능

- 기존 reports.html / reports.js와 실제 제보 API를 사용한다. 제보는 별도 MySQL에 저장한다.
- 회원/비회원 작성자, 접수 시각, 제보 당시 좌표·주소·개방시간을 조회한다.
- 없음/미개방의 확인 완료는 제보 상태만 변경한다. 시설 숨김/시간 변경을 자동 실행하지 않는다.
- 신규/위치 수정은 서버 주소 조회 성공 후에만 시설 생성/좌표 변경을 한다. 조회 실패 시 대기 상태와 시설을 보존한다.
- 새 관찰 제보는 개방시간 상세와 지번주소도 당시 값으로 저장한다. 이전 시험 제보에 누락된 당시 정보를 현재 값으로 소급해서 채우지 않는다.

## 격리 연결

`preview/report-local.mjs`는 표식이 있는 시험 메타데이터와 허용된 정적 파일만 읽는다. 운영 회원 쿠키는 전달하지 않고 시험 관리자 토큰만 loopback API에 사용한다. 운영 관리자 계정 로그인으로 가장하지 않는다.

`preview/report-gateway.mjs`는 preview.geupddong.com/admin-reports 전용이다. 공개 연결은 사용자 승인 후에만 배포한다. 별도 임시 접속 인증과 만료를 적용하며, 조회·승인·반려만 허용한다. 토큰은 URL에 넣지 않는다. 접속 쿠키는 HttpOnly/Secure, 변경 요청은 정확한 Origin과 JSON 본문 크기를 확인한다. 운영 API로 프록시하지 않는다.

로컬 연결은 loopback Host와 경로에 한정하고 POST Origin을 확인한다. 터널에는 httpHostHeader를 loopback 주소로 덮어쓰는 설정을 추가하면 안 된다. 외부 경로에는 별도의 gateway 키가 필요하다.
