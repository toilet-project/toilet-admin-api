# 관리자 경험치 랭킹

## 목적과 현재 상태

회원 관리의 `회원 목록 / 경험치 랭킹` 탭에서 회원의 현재 경험치와 휴지 등급 분포를 확인한다. 기존 회원 목록의 검색·상태 필터·페이지 이동은 유지한다. 실데이터 프리뷰 검수 후 별도 승인을 받아 운영에 반영한다.

## 조회 기준

- 대상은 활성·정지 회원이며 경험치 0인 회원도 포함한다. 탈퇴·동의 대기 회원은 제외한다.
- 경험치는 저장된 성장 계정 잔액을 읽는다. 조회 중 경험치를 재계산하거나 변경하지 않는다.
- 전체 순위는 경험치 높은 순의 공동 순위다. 동점은 `1, 1, 3`으로 표시하며 검색과 오름차순 정렬에도 전체 순위를 유지한다. 같은 경험치의 정렬은 회원 식별자 순으로 고정한다.
- 이름 일부 또는 전체 이메일 주소로 검색하고 10명씩 표시한다. 이메일은 기존 관리자와 같은 방식으로 마스킹한다.
- 분포는 검색과 무관한 전체 대상 회원 기준이다. 최초 진입과 명시적 새로고침에 갱신하며, 목록과 분포의 조회 실패는 각각 표시한다.

| --- | --- |
| 흰색 | 0–79 |
| 초록 | 80–239 |

| 핑크 | 6,240–15,989 |
| 검정 | 15,990 이상 |

## 접근과 개인정보

현재 관리자 권한이 있는 계정만 이용할 수 있다. 검색은 JSON 본문으로 전송하고 검색어를 주소·브라우저 저장소·통계·콘솔에 기록하지 않는다. 조회 응답은 저장하지 않는다. 권한 또는 세션이 만료되면 화면과 입력값을 비운다.

탭 변경이나 다른 메뉴로 이동하면 진행 중인 조회를 취소한다. 이전 화면의 늦은 성공·인증 오류 응답은 새 화면에 적용하지 않는다. 키보드 방향키·Home·End로 탭을 전환할 수 있으며 모바일에서도 순위·회원·등급·경험치를 함께 표시한다.

## 자산과 검증

휴지 아이콘 7개는 [웹 공식 v14 자산](https://github.com/toilet-project/toilet-web/tree/main/public/growth/rank-icons/v14/compact)을 변경 없이 관리자에 복사했다. 자체 디자인이나 별도 등급 기준을 추가하지 않는다.

합성 브라우저 검사는 관리자 인증 경계, 데스크톱·모바일, 공동 순위, 검색 본문의 개인정보 보호, 정렬·페이지 이동, 키보드 전환, 독립적인 실패·재시도, 늦은 응답과 인증 초기화를 확인한다. 실제 회원 데이터를 수정하는 검사는 수행하지 않는다.

실데이터 프리뷰 주소와 보호·만료·정리 절차는 [프리뷰 운영 문서](experience-ranking-preview.md)를 따른다. 전용 프리뷰는 경험치 랭킹만 연결하며 회원 목록과 운영 쓰기 요청은 연결하지 않는다.
