# 작성 리뷰 모니터링

## 목적과 화면

관리자는 서비스 이용 분석의 **작성 리뷰** 탭에서 전체 사용자의 리뷰를 확인한다. 방문 통계의 기간·기기·유입·봇 필터와는 독립된 전체 기간 목록이다.

- 작성 시각 내림차순으로 표시하며, 같은 시각에는 리뷰 번호 내림차순을 적용한다.
- 한 페이지에 20개씩 화장실명, 평점, 작성자, 작성·수정 여부를 보여 준다. 평점은 만족도와 청결도의 평균이다.
- 행을 클릭하거나 키보드로 선택하면 본문, 만족도, 청결도, 휴지 유무, 대기 시간, 작성·수정 시각을 펼친다.
- 공개 화장실은 서비스의 상세 페이지로 이동할 수 있다. 비공개 화장실의 리뷰도 관리자 목록에는 남는다.
- `service-analytics.html?tab=reviews`로 탭을 직접 열 수 있다. 새로고침하면 최신 리뷰부터 다시 조회한다.

## 데이터와 접근

조회 API는 `toilet-api`의 `GET /api/admin/v1/reviews`와 `GET /api/admin/v1/reviews/{id}`를 사용한다. 목록에는 본문을 포함하지 않고 선택한 리뷰의 상세만 별도로 조회한다. 다음·이전 이동에는 커서를 사용해 큰 페이지 번호에 따른 누적 조회를 피한다.

API는 관리자 권한과 현재 계정 상태를 검사한다. 이메일 등 연락처와 계정 식별자는 응답에 포함하지 않으며, 작성자 연결 해제·탈퇴·비활성 계정의 과거 표시명을 노출하지 않는다. 리뷰 응답은 개인 캐시와 공유 캐시 모두에 저장하지 않는다. 본문은 HTML이 아닌 텍스트로 표시한다.

데이터 없음, 목록 조회 실패, 상세 조회 실패·삭제, 로그인 만료를 구분한다. 탭·페이지 이동 후 도착한 이전 응답은 새 화면을 바꾸지 않는다. 이 화면은 조회용이며 리뷰 수정·삭제 기능은 포함하지 않는다.

## 적용 순서와 검증

- API 변경과 조회용 인덱스의 별도 운영 승인·배포 후 관리자 화면을 적용한다. API가 먼저 준비되지 않은 경우 관리자 화면은 조회 실패와 재시도를 표시한다.
- 프리뷰에서도 요청할 때 실제 데이터를 조회한다. 리뷰 원문을 파일로 복사하거나 미리 저장하지 않으며, 프리뷰 조회 연결의 만료를 표시한다.
- API 검증: 관리자 접근, 현재 권한 회수, 최신순·동일 시각·페이지 중간 등록, 본문 분리, 익명화, 비공개 시설, 입력 오류.
- 화면 검증: 데스크톱·모바일, 키보드, 본문 문자 처리, 페이지 이동, 빈 목록·오류·재시도, 늦은 응답, 인증 만료, 관리자 내부 페이지 이동.

운영 배포는 프리뷰 검수와 별도 승인 후 진행한다.
