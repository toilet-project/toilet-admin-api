# 리뷰 운영 가이드와 삭제 안내

검수안 · `review-moderation-v1`. 이 문서와 관리자 화면은 운영 반영 전 검토 대상이다. 공개 이용약관·정책의 게시·시행, 운영 API 배포 또는 실제 리뷰 삭제를 완료했다는 뜻이 아니다.

## 목적과 판단 기준

화장실 이용 경험과 평가를 보호하면서 명확한 가이드 위반 리뷰를 관리한다. 단순한 낮은 별점, 불만, 시설에 대한 비판, 관리자의 의견과 다르다는 이유만으로 삭제하지 않는다. 본문이 없는 별점 리뷰도 정상적인 리뷰다.

관리자는 해당 리뷰의 전체 내용을 확인하고 아래 사유 중 실제로 확인된 위반에 맞는 하나를 선택한다. 추측이나 자동 탐지만으로 삭제하지 않는다. 사유가 불분명하거나 해당 항목에 맞지 않으면 처리하지 않고 추가로 확인한다.

| 사유 코드 | 관리자 표시 | 적용 기준 |
| --- | --- | --- |
| `SPAM` | 광고·스팸 | 화장실 이용 경험 대신 상품·서비스 홍보, 구매·가입 유도, 광고 링크를 주목적으로 작성한 내용 |
| `ABUSE` | 욕설·혐오·괴롭힘 | 사람이나 집단을 겨냥한 욕설·혐오 표현, 위협, 성적 괴롭힘 등 명확한 공격성 내용. 시설의 청결·불편에 대한 비판과 구분한다. |
| `PERSONAL_INFORMATION` | 개인정보 노출 | 본인·타인의 연락처, 상세 거주지, 계정·신분 식별정보 등 공개할 필요가 없는 개인정보를 담은 내용 |
| `IRRELEVANT` | 화장실 이용과 무관한 내용 | 화장실 이용 경험과 관계없는 게시글, 무의미한 문자의 반복 등. 짧은 리뷰나 별점만 있는 리뷰라는 이유로 적용하지 않는다. |
| `MANIPULATION` | 반복·조작 리뷰 | 복제·도배 또는 평점 조작 행위가 구체적인 근거로 확인된 리뷰. 비슷한 평점이나 반복 방문만으로 판단하지 않는다. |

‘기타’나 자유 입력 사유는 제공하지 않는다. 처리 이력에 리뷰 원문이나 개인정보가 다시 복제되는 일을 피하고, 포괄적인 사유로 삭제하지 않도록 한다.

## 사용자에게 공개할 가이드 문안

급똥 리뷰는 실제 화장실 이용 경험을 나누는 공간입니다. 청결, 시설, 이용 편의에 대한 솔직한 평가를 남겨 주세요. 낮은 별점이나 불편 사항을 적었다는 이유로 리뷰를 삭제하지 않습니다.

광고·스팸, 욕설·혐오·괴롭힘, 본인 또는 타인의 개인정보 노출, 화장실 이용과 무관한 내용, 구체적인 근거로 확인된 반복·조작 리뷰는 관리자가 검토 후 삭제할 수 있습니다. 삭제 시 작성 내용과 평가가 함께 제거되며 관련 집계에서도 제외됩니다. 본문 없이 별점만 작성한 리뷰도 같은 기준으로 보호합니다.

삭제 처리에 이의가 있으면 대상 화장실과 리뷰 작성 시점을 알려 문의해 주세요. 문의 내용에 타인의 개인정보를 다시 포함하지 않도록 주의해 주세요.

이 문안은 공개용 초안이며 현재 운영 웹의 약관·정책 페이지를 변경하거나 시행일을 확정하지 않았다.

## 관리자 화면 문구

- 상세 화면 버튼: **리뷰 삭제**
- 사유 선택 제목: **삭제 사유**
- 선택 안내: **확인된 가이드 위반 사유를 선택해 주세요. 낮은 별점이나 불만만으로는 삭제할 수 없습니다.**
- 확인 제목: **이 리뷰를 삭제할까요?**
- 확인 본문: **이 리뷰의 작성 내용과 평가가 함께 삭제되며, 공개 리뷰·내 리뷰·관련 집계에서 제외됩니다. 서비스 화면에서 복구할 수 없습니다. 삭제 사유와 처리 이력은 남습니다.**
- 최종 버튼: **리뷰 삭제** / **취소**
- 완료: **리뷰를 삭제했습니다. 최신 목록으로 이동합니다.**
- 다른 관리자가 먼저 삭제한 경우: **이미 삭제되었거나 더 이상 확인할 수 없는 리뷰입니다. 최신 목록을 다시 확인해 주세요.**
- 확인 이후 작성자가 수정한 경우: **리뷰가 수정되었습니다. 최신 내용을 다시 확인한 뒤 삭제해 주세요.**
- 연결 중 결과를 확인하지 못한 경우: **삭제 결과를 확인하지 못했습니다. 목록을 새로고침해 상태를 확인해 주세요.**
- 실데이터 프리뷰: **실데이터 프리뷰에서는 리뷰를 삭제할 수 없습니다.**

확인 화면에는 대상 화장실과 선택한 사유를 함께 표시한다. 사유 선택·확인 전에는 삭제 요청을 보내지 않는다. 중복 클릭을 막고, 서버가 완료를 확인한 뒤에만 성공으로 표시한다.

## 작성자에게 설명할 때 사용할 문구

> 작성하신 리뷰는 ‘{위반 사유}’에 해당하는 것으로 확인되어 급똥 리뷰 운영 가이드에 따라 삭제되었습니다. 화장실 이용에 대한 낮은 평점이나 불만 자체는 삭제 사유가 아닙니다. 처리에 이의가 있으면 리뷰 작성 시점과 대상 화장실을 알려 문의해 주세요. 문의 시 개인정보가 포함된 원문을 다시 공개하지 않도록 주의해 주세요.

이 문구는 문의 응대용 초안이다. 현재 변경은 작성자에게 알림·이메일을 자동 발송하지 않으며, 발송 여부를 성공으로 표시하지 않는다.

## 데이터 처리와 적용 제한

관리자 삭제는 이용자의 **작성자 정보 지우기**와 다르다. 작성자 정보 지우기는 기존 정책에 따라 원문·평가를 유지하지만, 관리자 삭제는 해당 리뷰 본문과 평가를 데이터베이스에서 제거한다. 앱 내 복구 기능은 제공하지 않는다. 삭제로 인한 공개 리뷰·평점·휴지·대기·혼잡 집계와 성장 보상 변경도 함께 검증한다. 삭제를 이유로 24시간 작성 제한을 초기화하지 않는다.

기존 감사 이력에는 처리자, 처리 시각, 리뷰 식별자, 선택한 사유와 가이드 버전 등 필요한 처리 근거만 남긴다. 삭제한 본문·작성자 이름·연락처·위치·사진을 감사 이력에 복사하지 않는다.

서비스 데이터베이스에서 삭제한 것이 과거 백업의 즉시 삭제까지 뜻하지 않는다. 과거 백업 복원 시 삭제한 리뷰가 다시 나타날 수 있으며, 복원 전에 별도의 검증된 삭제 재적용 절차가 필요하다. 기존 작성자 연결 해제 대장은 원문 삭제용 대장이 아니므로 이를 해결했다고 간주하지 않는다.

프리뷰는 운영 실데이터를 읽기 전용으로 조회한다. 실제 리뷰에 삭제 요청을 보내지 않고, 삭제·충돌·권한·집계·감사 기록 검증은 합성 데이터와 격리 데이터베이스에서 수행한다. 운영 반영과 실제 삭제 처리는 별도 단계다.
