# 경험치 랭킹 실데이터 프리뷰

## 범위

검수 주소는 `https://preview.geupddong.com/admin-experience-ranking/?tab=ranking`이다. 회원 관리의 경험치 랭킹만 연결하며 회원 목록은 운영 관리자에서 확인하도록 안내한다. 실제 만료 시각은 화면 상단의 한국시간 안내를 따른다. 운영 반영은 별도 승인 대상이다.

운영 DB를 복사하지 않는다. 운영 서버 안의 별도 한시 프로세스가 필요한 열만 조회하고, 이름과 마스킹된 이메일을 관리자 브라우저에 전달한다. 원본 이메일·암호문을 브라우저에 전달하지 않으며 암호화 이메일은 복호화하지 않는다. 과거 평문 이메일이 있으면 서버에서 마스킹한 결과만 전달한다. 검색어와 결과를 파일·로그·통계에 저장하지 않는다.

## 허용 요청

- `POST /api/admin/v1/growth/ranking/search`: 이름·전체 이메일 검색과 정렬·페이지 조회. DB에서는 읽기만 수행하며 이메일이 URL에 노출되지 않도록 JSON 본문으로 전달한다.
- `GET /api/admin/v1/growth/ranking/distribution`: 검색과 무관한 전체 대상 회원 분포.
- 그 외 회원 API와 쓰기 요청은 연결하지 않는다. 관리자 인증 확인과 허용된 정적 파일은 별도로 처리한다.

검색은 정확한 출처, JSON 형식, 2KiB 실제 본문 크기, 허용 필드만 검사한다. 검색어는 320자 이내이며 제어 문자를 허용하지 않는다. 정렬은 경험치 내림차순·오름차순, 페이지는 0~100,000, 페이지 크기는 10명으로 제한한다. 검색 조건을 URL query로 전달하면 거절한다.

## 인증·데이터 보호

- 로그인 교환은 브라우저별 난수 상태값과 암호화된 짧은 교환표로 연결한다. 세션은 호스트 전용 보안 쿠키이며 최대 15분, 전체 프리뷰는 절대 만료 2시간을 넘지 않는다.
- 페이지·정적 파일·조회 요청마다 운영 인증 서버에서 현재 `ADMIN` 권한과 로그인 만료를 다시 확인한다. 운영 인증 토큰을 한시 조회 서버로 전달하지 않는다.
- 한시 조회 서버는 별도 난수 키를 요구하며 MySQL 세션 자체의 읽기 전용 설정과 준비된 SELECT 허용 목록을 함께 적용한다. DDL·DML·운영 애플리케이션 실행은 허용하지 않는다.
- DB 접속 정보와 이메일 검색 HMAC 키는 운영 서버 메모리 안에서만 한시 프로세스에 전달한다. 이메일 복호화 키는 필요하지 않다.
- Worker 관측 로그와 컨테이너 로그를 끈다. 모든 응답은 저장 금지·검색 제외로 제공하며 원본 결과를 테스트 산출물에 남기지 않는다.

## 자원과 정리

프리뷰마다 고유 이름의 Worker, 서버 작업 폴더, 컨테이너, 터널을 만든다. 기존 운영 애플리케이션·DB 계정·환경·스키마를 변경하지 않는다. 컨테이너는 기존 런타임의 명시된 비루트 사용자, 읽기 전용 파일 시스템, 기능 권한 제거, 메모리 192MiB·CPU 25%·프로세스 64개 한도를 적용하며 호스트 연결은 루프백 포트로 제한한다.

생성 전에 동명 Worker·라우트·컨테이너와 포트 충돌을 확인한다. 변경 전 소유 의도를 남기고 배포 직후 실제 버전·라우트 소유를 확인한다. 중간 실패나 만료 정리는 기록한 이름·태그·버전·컨테이너·프로세스 신원이 일치하는 자원만 제거한다. 공개 웹 Worker와 운영 앱은 정리 대상이 아니다. 서버의 독립 만료 감시가 컨테이너·터널을 중지하고 코드 jar를 제거하며, 별도 만료 작업이 전용 Worker·키·두 라우트를 정리한다.

## 검증

인증·권한 철회·세션 변조·만료·잘못된 출처·검색 본문/URL 경계·정적 자산 보호와 다른 쓰기 차단은 합성 데이터로 검사한다. 배포 후에는 무인증 경계와 실제 관리자 로그인 화면을 확인한다. 실제 회원·경험치를 변경하거나 검색 결과를 로컬 파일에 저장해 검증하지 않는다.
