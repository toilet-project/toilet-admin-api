사용량을 읽는 기준

월말 예상 사용량월초부터 집계 시각까지의 하루 평균을 해당 월 전체 기간에 적용합니다. 첫 24시간은 예상을 보류합니다.

무료 쿼터 비교항목별 월 한도와 비교합니다. 일간 한도는 일평균 예상으로 표시하며 실제 하루 최대 사용량과 다를 수 있습니다. 다른 프로젝트와 공유하는 한도는 별도 사용량도 확인해 주세요.

월별 증가와 감소지난달 전체와 이번 달 월말 예상을 구분합니다. 미집계 월은 0으로 채우지 않으며, 서로 다른 집계 기준이나 일부 기간만 있는 월은 증감을 계산하지 않습니다.
